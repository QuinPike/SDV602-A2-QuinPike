# How To Run

1. Open your preferred terminal
2. Navigate to your project folder cd path/to/project
3. Create the virtual environment: python -m venv .venv
4. Acticate the environment (windows): .venv\Scripts\activate.bat
5. Install required packages - Read through requirements.txt to find all requried modules.
6. Verify the environment is active - you should see (.venv) in your terminal prompt
